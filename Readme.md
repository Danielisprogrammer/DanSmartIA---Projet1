# DanSmartIA

## Description
DanSmartIA est une application web qui combine un convertisseur intelligent multi-unités (monnaie, poids, distance, température) et une calculatrice mathématique simple mais complète. L'application dispose également d'un formulaire de contact pour recevoir des messages des utilisateurs.

L'objectif est de fournir un outil pratique, facile à utiliser, avec une interface responsive optimisée pour tous types d'écrans. L'application est conçue pour évoluer avec une future intégration d'une API d'intelligence artificielle afin d'améliorer les fonctionnalités.

---

## Fonctionnalités principales
- Convertisseur intelligent : conversions rapides entre différentes unités pour plusieurs catégories (monnaie, poids, distance, température).
- Calculatrice : opérations mathématiques de base (+, -, *, /), racine carrée, et puissance.
- Formulaire de contact : permet aux visiteurs d'envoyer directement un message via un formulaire sécurisé.
- Interface responsive pour un usage optimal sur mobiles, tablettes et ordinateurs.

---

## Prérequis
- Navigateur web moderne (Chrome, Firefox, Edge, Safari).
- (Optionnel) Serveur local pour tests avancés et déploiement.
- (À venir) Clé API pour intégration IA.

---

## Installation et utilisation locale
1. Télécharger ou cloner les fichiers du projet.
2. Ouvrir le fichier `index.html` dans un navigateur web.
3. Pour un usage avancé avec formulaire ou API, utiliser un serveur local (exemple : Live Server pour VS Code).
4. Configurer le formulaire de contact avec votre propre service (comme Formspree).

---

## Structure du projet
- `index.html` : structure HTML principale.
- `css/style.css` : styles standards.
- `css/responsive.css` : styles responsive.
- `js/app.js` : gestion de la navigation entre sections.
- `js/convertisseur.js` : logique du convertisseur.
- `js/calculatrice.js` : logique de la calculatrice.
